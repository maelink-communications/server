## Available clients for this server

> [!NOTE]
> ❌ means that the client is not supported on the latest version of the server, or at least has some pretty bad bugs that break the client.<br>
> ⚠️ means that the client is supported on the latest server version or is partially supported with minor bugs, and/or supports *basic* functions, but possibly not more advanced ones like Bubbles or profile editing.<br>
> ✅ means that the client is fully supported, and supports at least a very substantial part of the protocol.

| name                   | capabilities                 | supported?  | latest server version supported:         | github / url            |
| ---------------------- | ---------------------------- | ----------- | ---------------------------------------- | ----------------------- |
| Pancake by NotFenixio  | Sign in, register, see Home posts, edit your bio, and basic Bubbles functionality | ✅ | v0.5.0 beta   | <https://github.com/NotFenixio/pancake> |
| waechain by Kabezz     | All (current) auth, Home and Inbox interactions (as of client build 20260710a2h1 and server v0.5.0 beta) | ⚠️ | v0.4.0 (works on v0.5.0 beta) | <https://github.com/Kabezz/waechain-maelink> |
| Solstice by Scratchy2  | Most (current) auth, Home and Inbox interactions | ⚠️ | v0.5.0 beta | <https://solstice52.github.io/>      |
| yorlink by Zagyen8913  | Most (current) auth, Home and Inbox interactions. User settings *seem* to be planned but not implemented. | ⚠️ | v0.5.0 beta (current version made for v0.3.X?) | <https://zag.lunarsphere.net/yorlink/> |
